Exercício 10

Faça um programa que pergunte em que turno você estuda. Peça para digitar:

  • M - Matutino
  • V - Vespertino
  • N - Noturno

Imprima a mensagem "Bom Dia!", "Boa Tarde!" ou "Boa Noite!" ou "Valor Inválido!", conforme o caso. 

let turno = (prompt("Digite qual turno você estuda.").toLowerCase());

let saidaConsole = "";
switch (turno) {
    case "matutino":
    case "m":
        saidaConsole = "Seu turno é matutino.\nBom dia!";
        break;
    case "vespertino":
    case "v":
        saidaConsole = "Seu turno é vespertino.\nBoa tarde!";
        break;
    case "noturno":
    case "n":
        saidaConsole = "Seu turno é noturno.\nBoa noite!";
        break;
    default:
        saidaConsole = "Erro. Tente escrever novamente."    
};

console.log(saidaConsole);
