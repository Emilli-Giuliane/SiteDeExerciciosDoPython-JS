Exercício 27

Uma fruteira está vendendo frutas com a seguinte tabela de preços: 

                        Até 5 Kg                    Acima de 5 Kg
Morango         R$ 2,50 por Kg          R$ 2,20 por Kg
Maçã              R$ 1,80 por Kg            R$ 1,50 por Kg

Se o cliente comprar mais de 8 Kg em frutas ou o valor total da compra ultrapassar R$ 25,00, receberá ainda um desconto de 10% sobre este total. Escreva um algoritmo para ler a quantidade (em Kg) de morangos e a quantidade (em Kg) de maças adquiridas e escreva o valor a ser pago pelo cliente. 

let qntMorango = parseFloat(prompt("Quantidade em Kg de Morangos a ser comprado"));
let qntMaca = parseFloat(prompt("Quantidade em Kg de Maçã a ser comprado"));
let totalKg = qntMorango + qntMaca;
let totalMorango = 0;
let totalMaca = 0;
let totalValor = 0;
let saidaConsole = `${qntMorango}Kg em Morangos;\n${qntMaca}Kg em Maçãs.`;

if (totalKg <= 5) {
    totalMorango = 2.50;
    totalMaca = 1.80;

    totalValor = (totalMorango * qntMorango) + (totalMaca * qntMaca);
    saidaConsole += `\nValor a ser pago R$${totalValor}`;
} else if (totalKg > 5) {
    totalMorango = 2.20;
    totalMaca = 1.50;

    totalValor = (totalMorango * qntMorango) + (totalMaca * qntMaca);
    saidaConsole += `\nValor a ser pago R$${totalValor}`;
}
if (totalKg > 8 || totalValor > 25.00) {
    totalValor -= (totalValor * 0.1);

    saidaConsole += `\nVocê ganhou desconto de 10%. O novo valor a ser pago será de R$${totalValor}`;
}

console.log(saidaConsole);
