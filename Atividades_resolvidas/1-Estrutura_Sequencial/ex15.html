Exercício 15

Faça um programa que pergunte quanto você ganha por hora e o número de horas trabalhadas no mês. Calcule e mostre o total do seu salário no referido mês, sabendo-se que são descontados 11% para o Imposto de Renda, 8% para o INSS e 5% para o sindicato, faça um programa que nos dê:

  • salário bruto.
  • quanto pagou ao INSS.
  • quanto pagou ao sindicato.
  • o salário líquido.
  • calcule os descontos e o salário líquido, conforme a tabela abaixo:
    Formula

    + Salário Bruto : R$
    - IR (11%) : R$
    - INSS (8%) : R$
    - Sindicato ( 5%) : R$
    = Salário Liquido : R$

Obs.: Salário Bruto - Descontos = Salário Líquido.

let ganhaHoras = prompt("Para mostrar a atividade a seguir, siga as instruções.\nDigite o quando você ganha por horas trabalhadas:");
ganhaHoras = parseFloat(ganhaHoras.replace(",","."));
let horasTrabalhadas = parseInt(prompt("Digite a quantidade de horas trabalhadas no mês:"));

// Calcular total do salário ao mês
let calcTotalSalMês = ganhaHoras * horasTrabalhadas;
calcTotalSalMês = parseFloat(calcTotalSalMês.toFixed(2));

// sabendo-se que são descontados 11% para o Imposto de Renda
let comImposto = 0.11 * calcTotalSalMês;
comImposto = parseFloat(comImposto.toFixed(2));
// 8% para o INSS
let comINSS = 0.08 * calcTotalSalMês;
comINSS = parseFloat(comINSS.toFixed(2));
// 5% para o sindicato
let comSindicato = 0.05 * calcTotalSalMês;
comSindicato = parseFloat(comSindicato.toFixed(2));

let salarioLiquido = parseFloat((calcTotalSalMês - (comImposto + comINSS + comSindicato)).toFixed(2));
// salarioLiquido = parseFloat(salarioLiquido.toFixed(2));        

let saidaConsole = `Salário bruto: R$${calcTotalSalMês}.\nQuanto pagou ao INSS: R$${comINSS}.\nQuanto pagou ao sindicato: R$${comSindicato}\nO salário líquido: R$${salarioLiquido}.`;
console.log(saidaConsole);
