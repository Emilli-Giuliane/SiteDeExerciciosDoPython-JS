Exercício 18

Faça um programa que peça o tamanho de um arquivo para download (em MB) e a velocidade de um link de Internet (em Mbps), calcule e informe o tempo aproximado de download do arquivo usando este link (em minutos). 

alert("Esse programa irá calcular o tempo aproximado até o termino do download de um arquivo. Siga as instruções.");
// peça o tamanho de um arquivo para download (em MB)
let download = parseFloat(prompt("Digite o tamanho do seu arquivo para dowload (em MB)"));
let velLink = parseFloat(prompt("Digite a velocidade do link de internet (em Mbps)"));

let tempo = ((download * 8) / velLink) ;
let tempoMin = tempo / 60;

let saidaConsole = `O tempo necessário até concluir o download será de ${tempoMin.toFixed(2)} Minutos.`;
console.log(saidaConsole);
